# Fonts

The three typefaces of the design system, as variable web fonts for the showcase and the visuals.

| File | Family | Used for | Copyright |
|---|---|---|---|
| `DynaPuff-Variable.woff2` | DynaPuff | Display type, titles, button labels, scores | Copyright 2021 The DynaPuff Project Authors |
| `Nunito-Variable.woff2` | Nunito | Running text | Copyright 2014 The Nunito Project Authors |
| `Inconsolata-Variable.woff2` | Inconsolata | Labels, readouts, callsigns | Copyright 2006 The Inconsolata Project Authors |

The app bundles static instances of the same families in `app/src/shared/src/commonMain/composeResources/font/`.
