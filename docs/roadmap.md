# Roadmap

1. **Scaffold** – KMP + Compose project, Android host, empty game screen.
2. **Core engine** – aircraft, path following, straight-on flight, unit tests.
3. **Input** – tap-select and drag-draw paths.
4. **Landing** – runways, helipads, landing rules, scoring.
5. **Variety** – multiple aircraft types and speeds, spawner, difficulty ramp.
6. **Failure states** – collisions, misses, lives, game over.
7. **Polish** – cartoon art, animations, sound, menus.
8. **Levels** – multiple airport layouts.
9. **iOS** – add `iosApp` host and verify.
