# Proposal

GitHub issue: #31

## Why

On a phone held in landscape the game ended dialog and the options panel ("Paused") are taller than the screen, so the player has to scroll to reach the buttons, mid-game. The stacked portrait Dialog from the design system is the only layout the game has; there is no variant for a short screen.

## What Changes

- Add a **compact Dialog variant** to the design system first (`docs/design-system/`: tokens, `bundle.css`, the Dialog section of `showcase.html`, `components/Dialog.md`): a wider card with tighter spacing, a smaller title style from the existing type scale, actions side by side, and stats beside the title instead of under it. Outline, `radius-xl`, lip and soft shadow, DynaPuff title, Inconsolata body, toy-block buttons and the drop-in stay.
- Build the same variant in the Compose theme (`ui/theme`, regenerated from `tokens.json`) and in `FaDialog`, which picks it on its own when the screen is landscape and short. Portrait stays exactly as it is.
- Lay out the game ended dialog (title, reason, per-type wells, Total landed, Points, Try again, Main page) and the options panel (Paused, body, Continue, Restart, Quit) so both fit without scrolling on common phones in landscape, with the ad banner under the game ended dialog.
- Keep the `verticalScroll` in `FaDialog` only as a last resort for screens smaller than common phones or large font scaling.

Out of scope: new dialog content or copy; moving or resizing the ad banner; tablets and foldables beyond "nothing gets worse"; other screens (main page, level select, HUD). The main page's quit dialog uses `FaDialog` and inherits the variant, but it carries no acceptance criteria of its own.

Depends on: `player-hud` (the options panel and its `pause-menu` spec) and the archived `game-ended-dialog` (the dialog and its banner via `level-start-ads`). The code for both dialogs is already on `development`.

## Capabilities

### New Capabilities

- `dialog-layout`: how modal dialogs are laid out per screen shape: the portrait layout from the design system, the compact landscape layout, and the guarantee that the game ended dialog and the options panel fit common phones without scrolling.

### Modified Capabilities

None. The content and actions of `game-ended-dialog` and `pause-menu` do not change.

## Impact

- `docs/design-system/`: `tokens.json`, `bundle.css`, `showcase.html` (inline CSS and the Dialog section), `components/Dialog.md`.
- `shared/commonMain` `ui/theme` (`FaDimens` regenerated by `tools/gen-kotlin.cjs`), `ui/components/FaDialog.kt`, `ui/game/GameEndedDialog.kt`, `ui/game/Hud.kt` (`OptionsPanel`).
- No engine, domain or platform changes.
